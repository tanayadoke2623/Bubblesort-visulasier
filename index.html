Bubble Sort Logic

JS 
for (let i = 0; i < n; i++) {
  for (let j = 0; j < n-i-1; j++) {
    if (arr[j] > arr[j+1]) {
      swap(arr[j], arr[j+1]);
    }
  }
}

Compare neighboring values. Swap them when the left value is larger. Repeat until sorted.
